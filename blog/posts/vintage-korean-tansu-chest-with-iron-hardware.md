This gorgeous Korean Tansu-style chest with iron hardware features five drawers of various sizes and a spacious central compartment. A charming fish shaped lock can be used to secure the cabinet doors. Decorative iron plating adds an aesthetic flourish to this elegant and functional storage solution. Tansu are traditionally mobile cabinets; handles on the side make this chest fairly easy to transport.

Chest: 22"(h) x 19.75"(w) x 13"(d) 
Top drawers: 2" x 8" x 11"
Central compartment: 7" x 19" x 12"
Small bottom drawers: 2" x 6" x 12"
Large bottom drawer: 2" x 14" x 11.75"
